## 📂 프로젝트 목록

### 1️⃣ DigitalNote.apk
**디지털 노트를 직접 만들어보자는 취지에서 해본 시도로 현재 미완성이다.**

* 왜인지는 모르겠지만 현재 펜으로 글을 쓰는게 불가능해서 코드를 뜯어보고 ai로 코드를 고쳐보아도 펜으로 글씨가 써지지를 않는다
* 디자인은 ai를 통해 만들었다
* 코드도 도형 부분이나 라텍스기호 변환같은 부분또한 ai가 추가해주었다

### 2️⃣ sun_terrain.apk
**태양궤도와 산의 높이를 통해 산에사는 사람이 수평선에 사는 사람처럼 낮게 해가 지지 않는 사람들에게 필요할 듯 싶어서 만들어본 어플이다.**

* 현재 위젯의 크기로 인해 제대로 해의 경로가 잘 보이지는 않지만 그래도 고도 계산은 잘되는 부분이다.
* 현재 날씨앱으로 변경되었으며 달 또한 정상작동한다. 비 레이더를 추가는 했지만 실제 데이터와 맞지를 않아서 오차를 수정중이다.
* 태양 궤도에대한 수식은 ai에게 작성해달라고 부탁했다. 디자인도 마찬가지로 ai가 작성해줬다.

### 3️⃣ LIttelWars.apk
**골드메탈이라는 유튜버에게 에셋을 받아 게임을 만들어보았다.**

* 상대방(ai)와 싸우는 간단한 RTS 게임이라고도 볼 수 있겠다.
* 📺 **참고 영상:** [Youtube Link](https://www.youtube.com/watch?v=IONpYgEfk40&list=PLO-mt5Iu5TebYBC5jE3u5LyP2D7np0jJf)

### 4️⃣ Jelly Farm.apk
**이것 또한 골드메탈이라는 유튜버에게 에셋을 받았는데 귀여운 젤리들을 해금하면서 힐링하는 게임이다.**

* 📺 **참고 영상:** [Youtube Link](https://www.youtube.com/watch?v=G6NronfnXfg&list=PLO-mt5Iu5TeZA0y889ZMi9wJafthif03i)

### 5️⃣ AI 입법 수요 분석을 위한 전처리 파이프라인
**이건 경상남도 교육청에서 주최하는 ai 인재 양성 미래학교라는 곳에서 같이 만들어본 걸로써 공모전에 참여했던 작품이다.**

* 비록 탈락했지만.
* 그당시에 같이 했던 팀원들과 같은 공간에서 대화하지 못해서 엄청나게 많은 주석을 달아놓았다.
* 코랩으로 만들었다.
