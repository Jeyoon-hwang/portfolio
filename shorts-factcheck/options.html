🔍 유튜브 쇼츠 팩트체크 - API 키 설정

아래 3개의 API 키는 이 브라우저의 chrome.storage.local에만 저장되며, 외부 서버로 전송되지 않습니다.

⚠️ 이 확장 프로그램은 개인 사용을 전제로 합니다. 키가 로컬에 평문으로 저장되므로, 이 브라우저 프로필을 다른 사람과 공유하지 마세요.
댓글 수집에 사용됩니다. Google Cloud Console에서 발급 (일일 쿼터 10,000유닛 무료).
댓글 분류, 반박 댓글 주장 추출(Flash-Lite)과 Google 검색 그라운딩을 활용한 팩트체크 최종 판정(Pro)에 모두 사용됩니다. 프로젝트 코어 기능입니다.
원본 영상 찾기(버튼 클릭 시에만 사용, 자동 실행 없음)에 사용됩니다.
